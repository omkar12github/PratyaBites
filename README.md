# 🍔 PratyaBites

> **Pratya's Promise, Every Bite.**

## About

PratyaBites is a 100% Pure Vegetarian Cloud Kitchen platform that allows customers to order fresh, hygienic, and delicious vegetarian fast food directly from the website.

The project is being built from scratch as a complete startup using modern web technologies.

---

## Vision

To become one of India's most trusted Pure Vegetarian Cloud Kitchen brands.

---

## Mission

- Fresh Food
- Fast Delivery
- Great Customer Experience
- Affordable Pricing
